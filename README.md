# Nova AI Chat UI

A responsive, dependency-free AI chat interface demo built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive desktop/mobile layout
- New chat and clear chat controls
- Enter-to-send composer
- Simulated assistant responses
- No API key required

## Run
Open `index.html` in a browser. To make it a real AI chat, replace the simulated response logic in `script.js` with a secure backend API call.
